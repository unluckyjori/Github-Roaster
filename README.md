# Github Profile Roaster

The Github Profile Roaster is a simple, but effective app that will roast you based on your github repositories.

## Functions

**Backend** -> **GitHub**
- Obtain GitHub repository data

**Backend** -> **Gemini** 
- Obtain Gemini AI response

**Backend** -> **Frontend**
- Send reponse to Frontend

## Technologies Used

- **Spring**
    - Server hosting and rest communication

- **Java**
    - Backend langauge

- **HTML, CSS, JavaScript**
    - Frontend languages to display content and handle communication to Backend
